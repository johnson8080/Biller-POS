# Biller POS - advertisement

The film is **Biller-POS-ad.mp4**: 1 minute 51 seconds, 1080 x 1920 (vertical,
9:16), MP4 with the original instrumental track and the English narration.
It is ready to post on WhatsApp, Facebook, Instagram and TikTok.

## What is in here

| File | What it is |
| --- | --- |
| `Biller-POS-ad.mp4` | The finished advertisement |
| `ad-builder.html` | Draws the film on a canvas: phone mock-up, captions, and the music engine |
| `record-ad.js` | Drives Chrome to record the film and write the MP4 |
| `fix-mp4-duration.js` | Writes the real length into the MP4 header (Chrome records a zero duration) |
| `frames/` | The app screens that appear in the film |
| `audio/` | The narration, one file per line |
| `VOICE-OVER.md` | The script, in Kiswahili and English, with timings |

## Recording your own voice (recommended)

The film currently has an English narration. To use your own Kiswahili voice:

1. Read the Kiswahili lines in `VOICE-OVER.md`.
2. Save one **WAV** file per line into `audio/`, using the same names
   (`line-00.wav` ... `line-14.wav`). 16-bit WAV, any sample rate, mono or
   stereo.
3. Run `node record-ad.js` again.

The film re-times itself from the length of each file, so you do not have to
match the timings exactly - but keep the pauses short, or the film gets long.

## Rebuilding the film

```bash
npm i puppeteer-core            # once
node record-ad.js              # writes Biller-POS-ad.mp4
node fix-mp4-duration.js Biller-POS-ad.mp4
```

`fix-mp4-duration.js` is needed because Chrome's recorder leaves the length of
the MP4 at zero; without it, players show the film as a few seconds long.

## Changing things

- **The price** - search for `KES 600 / mwezi` and the price in the captions
  inside `ad-builder.html`.
- **The WhatsApp number** - it is in the last scene of `ad-builder.html` and in
  the narration file `audio/line-14.wav`.
- **The screens** - drop new PNGs into `frames/` (780 x 1688, 2x of a 390 x 844
  phone) and point the scene at them.
- **A shorter ad** - remove scenes from the `SCENES` list at the top of
  `ad-builder.html` and record again. A 20 second version is just the title
  card, the sell screen, the scanner and the M-Pesa prompt.

## The music

The instrumental track is generated by the page itself (a warm pad, a soft
bass, a marimba-like melody and light percussion over a C - Am - F - G
progression at 90 beats per minute). Nothing was downloaded and nothing is
copyrighted: it belongs to you and can be used in paid ads.
